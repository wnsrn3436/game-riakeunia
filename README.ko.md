# 리아크늬아

[English](README.md)

세로 스크롤 슈팅이다. 초상화가 붙은 대사창으로 스토리를 진행하고 체력바가 있는 보스전을 2탄까지 넣었다.

## 플레이 방법

Releases에서 받아 실행하면 된다.

방향키로 움직이고 스페이스로 미사일을 쏜다. Ctrl은 궁극기다. A를 누르면 저장, D를 누르면 불러오기 확인창이 뜬다.

게임 중에 F, D, Z를 순서대로 누르면 방어막이 생긴다. 캐릭터를 따라다니며 적 미사일을 막고 미사일을 자동으로 쏘다가 적 몸체에 부딪히면 사라진다.


## 구현 원리

치트 커맨드는 오브젝트를 갈아 끼우는 방식으로 만들었다. 변수로 입력 순서를 기억하는 대신, F를 받는 오브젝트가 F를 누르면 D를 받는 오브젝트로 자기 자신을 바꾸고, 그게 D를 누르면 다시 Z를 받는 오브젝트로 바뀐다. Z까지 눌리면 방어막 오브젝트를 만들고 사라진다. 오브젝트 종류가 곧 상태인 셈이라 Change Object 액션 하나씩만 걸어두면 됐다.

저장과 불러오기는 게임메이커의 Save Game, Load Game 액션을 그대로 썼다. 확인창을 먼저 띄우고 예를 누르면 `savegame` 파일에 상태를 통째로 쓴다.
